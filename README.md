# 🌌 Space

What started as an attempt to make a single galaxy… turned into a whole universe.

Now it’s **two experiences in one:**

- **v1:** 🚀 _Explore the vast universe_ (open-world camera, infinite galaxies)
- **v2:** 🌠 _Dive into focused galaxy modes_ (Galaxy, Portal, Galaxy Collapsing)

---

## 🚀 Description

**Space** is a WebGL universe built with React Three Fiber. It features:

- Thousands of procedurally generated galaxies and stars
- Dynamic camera modes
- Stunning procedural visuals

Best experienced in fullscreen.

---

## ✨ What's New (v2)

- 🌌 **Galaxy Mode:** Classic swirling galaxy with natural movement
- 🌀 **Portal Mode:** Sci-fi portal with swirling particles and glowing effects
- 💥 **Galaxy Collapsing Mode:** A dramatic collapse-and-explosion sequence (particles spiral inward, then burst outward)
- 🎛️ **Interactive Controls:** Switch modes on the fly
- 🌈 **Dynamic Color Shifts:** Visual styles change per mode (pulses, glows, explosions)

> ✅ Access v2 via `/`  
> ✅ Access v1 via `/v1`

---

## ✨ Features (v1)

- 50+ unique, rotating galaxies
- Dynamic starfields with varied textures
- Procedural positions, colors, and movement
- Smooth free-fly camera with full mouse look
- Scroll and keyboard-based navigation
- Fully responsive, fullscreen toggle support

---

## 🎮 Controls (v1)

| Action        | Input                   |
| ------------- | ----------------------- |
| Move forward  | `W` or `↑`              |
| Move backward | `S` or `↓`              |
| Strafe left   | `A` or `←`              |
| Strafe right  | `D` or `→`              |
| Move up/down  | `Q` / `E`               |
| Look around   | `Mouse` (after click)   |
| Zoom          | `Mouse Scroll`          |
| Fullscreen    | `Double Click anywhere` |

> 💻 Best experienced on desktop with a mouse.
